# Pyra-API

Wyklankerowany tłumacz gwary Poznańskiej.

## Co i jak

Ogarnia pełne zdania. Output jest średni, ale działa. Zajrzyj do `API.md` żeby ogarnąć jak z tego korzystać. Chiński klanker zrobił za 20 centów (https://openrouter.ai/deepseek/deepseek-v4.1-flash).

## Licencja

Mordo, cały ten kod napisał klanker. Rób se co chcesz.

A słownik został wyciągnięty z [www.poznan.pl](https://www.poznan.pl/mim/slownik/). Dziękuję cieplutko za słowniczek i pozdrawiam!!!

## Przykład

Przetłumaczona pasta o wiadomo kim:

```bash
curl --get --data-urlencode text@ojciec.txt http://127.0.0.1:8080/translate | jq -r .translation
```
